# Mein Haus / Shtëpia Ime / My Home
PWA + Android household manager for offers, shopping, inventory, finance, bills and AI.

## Backend
Google Apps Script endpoint is configured in `app.js`. Secrets such as `OPENAI_API_KEY` stay server-side.

## Android
GitHub Actions builds an installable debug APK after every push to `main`. Download the artifact named **MeinHaus-APK** from the latest Actions run.
