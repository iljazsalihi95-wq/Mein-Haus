## Source repairs

- Fixed two fatal app.js parse errors and missing appointment renderer calls.
- Fixed a DOM insertion error and an authenticated-startup initialization-order error.
- Required validated session before private page navigation; isolated family/finance/bill/appointment/receipt caches by session. Preserved old unscoped cached data without rendering it in another session.
- Removed hard-coded personal appointment bootstrap data from current source. Original git history remains in recovery refs; no history rewrite performed.
- Server lists replace cached members and appointments so deleted records do not reappear.
- Password reset no longer returns the reset secret to the public caller; it sends the code to the stored email and invalidates undeliverable codes. Requires MailApp authorization in the actual deployment. Added request cooldown. Existing password hashing algorithm has not been migrated.
- Added server restrictions against member role escalation and attaching arbitrary account IDs through familyMemberSave.
- Rejected malformed session expiry, invalid/negative/infinite financial amounts, and unknown transaction types; restored bank/cash field mapping.
- Added endpoint-specific push-subscription deactivation on logout and session cache cleanup. This does not implement a push delivery service.
- Added a lock and family-scoped idempotence for repeated shopping additions with the same offer ID.
- Offer-country coverage now discovers existing Oferta_XX tabs instead of a fixed list. Explicit requested location takes precedence. Filters exclude future and expired offers; responses cannot overwrite a newer location request.
- Removed old static offer bootstrap entries; empty server responses clear old results. Missing photos remain neutral. Home store tabs select the actual displayed store.
- Disabled the legacy HTML/AI scraping importer with AUTHORIZED_FEED_REQUIRED; existing offers are preserved. No new licensed provider was fabricated or connected.
- AppCreator24 home: repaired broken HTML escaping, duplicate image src attributes, API name/date aliases, offer ID matching and dynamic coverage loading. All original go: destinations retained.
- Service worker caches only its own app resources, removes only this app's old caches, and does not substitute HTML for external APIs/images.
- Foreground appointment reminders respect stored minutes, deduplicate delivery and hide personal detail by default. Closed-app delivery remains unimplemented.
- Added reproducible backend/DOM tests and expanded GitHub CI.
